Experiments Catalog

every experiment opthub can run · which session to replay · how the result is verified

Each experiment takes one real Claude Code session, changes one thing, and checks whether the job still gets done for less money. Open a row to see which session to use, how the result is checked, and how much it could save.

Potential saving is measured on the pinned E1b month: 214 sessions, $508.80 at API list price (docs/data/e1b-sessions.csv). Each figure is that lever alone. Figures do not add up.
