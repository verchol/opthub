scenarios.jsonEvery scenario: layer, where it applies, the parameters it changes (knob, value, where), trust label, quality risk, latency effect, opthub evidence, caveat.
engine.jsThe pricing engine as pure functions. AtlasEngine.evaluate(workload, scenarios) returns best and worst case per scenario, with the sentence that explains each.
llms.txtA plain-text summary for language models: what the atlas is, the files, the workload fields and the trust labels.
const E = require('./engine.js'), { scenarios } = require('./scenarios.json')
const w = { ...E.defaults(), devs: 25, model: 'claude-opus-5', hit: 80 }
E.evaluate(w, scenarios).sort((a, b) => b.worst - a.worst).slice(0, 5)
Prices are Anthropic list rates per million tokens, input / output: Opus 5 $5 / $25, Opus 5.5 $4 / $20, Sonnet 5 $2 / $10, Haiku 4.5 $1 / $5, Fable 5.1 $10 / $50. Cache reads bill at 0.1× input, 5-minute cache writes at 1.25×, Batch at 0.5×, fast mode at 2×. Partner platforms (Bedrock, Vertex AI) price separately.
Workload defaults approximate one developer’s measured month in opthub, scaled to a team of ten. Measured figures come from SPEC.md §2 and the J3 session triage. They are small samples and say so.
