Work under strict context discipline:

- Read each file at most once. If you need it again, rely on what you already read.
- Never print a file back into the conversation to look at it.
- Prefer one command that answers several questions over several that each answer one.
- Do not restate the spec, summarise your progress, or narrate what you are about
  to do. Produce the artifact.
